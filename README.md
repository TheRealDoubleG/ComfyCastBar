# ComfyCastBar

**Version 0.1 – Beta**

Customizable cast bars for **World of Warcraft: Forever**.

## 0.1 Beta

- Player, target, focus and pet cast bars.
- Cast and channel support.
- Interruptible / non-interruptible visual states where the client exposes that information.
- Spell icon, spell name and remaining time.
- Optional player latency zone.
- Movable bars with standalone unlock mode and ComfyHub Suite Edit Mode integration.
- Minimal, Standard and PvP presets.
- Character, account and custom profiles.
- Optional hiding of the Blizzard player cast bar.
- WoW Forever secret-value aware cast handling: values are passed to widgets where possible and only inspected when safe.

## Commands

- `/ccb`
- `/ccb test`
- `/ccb unlock`
- `/ccb lock`
- `/ccb reset`

## Target

WoW Forever 1.60.1 / Interface 16001.

ComfyCastBar changes the UI only and does not automate gameplay.
